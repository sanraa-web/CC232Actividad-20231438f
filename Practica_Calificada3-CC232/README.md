## Problema Asignado
**C - データ構造 (Data Structure / Estructura de Datos)**

El problema solicita administrar un conjunto dinámico de números (inicialmente vacío) ue responda $Q$ consultas de dos tipos:

1. **Inserción ($T = 1$):** Agregar un número $X$ al conjunto.
2. **Consulta y Eliminación ($T = 2$):** Identificar el $X$-ésimo número más pequeño presente en el conjunto, imprimirlo y luego eliminarlo.

**Restricciones clave:**
* Número de consultas y valores: $1 <= Q,X <= 200,000$.
* No se insertarán números repetidos que ya existan en el conjunto.
* Nunca se pedirá eliminar un elemento si no hay suficientes elementos disponibles.
